# Good first issues

A small, curated list of verified starter tasks for new contributors. Every item here has been confirmed against the current code and test suite — pick one, comment on its issue to claim it, and open a PR once you're assigned (see [CONTRIBUTING.md](./CONTRIBUTING.md#ai-assisted-and-automated-contributions)). Optionally pair with the `guide-me` skill.

> This list is intentionally small and **verified**. Do not add an item unless you have confirmed the gap exists in the code or tests. If you want something else, open an issue or ask in the issue tracker.
