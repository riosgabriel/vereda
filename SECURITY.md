# Security Policy

## Supported Versions

Only the latest release on the `main` branch is supported with security fixes.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately using GitHub's [private vulnerability reporting](https://github.com/riosgabriel/vereda/security/advisories/new):
go to the **Security** tab of the repository, then **Report a vulnerability**.

You can expect an initial response within a few days. Please give us a reasonable
amount of time to investigate and release a fix before any public disclosure.
